# HWS Adminko 2.0 — каркас (мок-данные)

Реальный Next.js/React-фронтенд новой админки HWS Store. Не картинка и не кликабельный макет — рабочий код, готовый к тому, чтобы в `lib/mock/data.ts` заменить функции-заглушки на настоящие вызовы API/Prisma без переписывания компонентов.

## Что уже собрано

- Общий каркас: сайдбар (`components/app-sidebar.tsx`), верхняя панель (`components/app-topbar.tsx`), корневой layout (`app/layout.tsx`).
- Группы меню и пункты — по решениям из ТЗ «Админко 2.0» и «Экранных спецификаций» (Outline, коллекция HWS | Store), а не по текущей проде:
  - без группы «Парсинг и обработка» (удалена целиком);
  - без отдельного пункта «Фильтры» (видимость фильтра теперь тумблер на Атрибуте);
  - новая группа **«Магазин»**: Оплата/Доставка + Ценообразование;
  - в «Администрировании» — новый пункт **«Пользователи»**, «Ценообразование» оттуда убрано (переехало в «Магазин»).
- Страница «Панель управления» — с рабочими стат-плитками на мок-данных.
- Остальные экраны — заглушки (`components/screen-placeholder.tsx`), чтобы навигация была полностью рабочей уже сейчас; содержимое каждого экрана — следующий шаг, по одному, по спецификациям.
- Мок-данные — `lib/mock/data.ts`: бренды, категории, товары, пользователи, история изменений. Формы объектов ориентированы на архитектуру из справочника (Entry/Route/Placement и т.п.), где это уже спроектировано.

## Стек

Next.js 16 (App Router, Turbopack), React 19, TypeScript, Tailwind CSS v4. Компоненты `components/ui/*` написаны вручную в духе shadcn/ui (Sidebar, Button) — CLI `shadcn init` недоступен из этого окружения (сеть блокирует `ui.shadcn.com`), поэтому набор компонентов пока минимальный, добавляется по мере проработки экранов.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию — `http://localhost:3000`.
